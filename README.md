# Medicare Information Pro — Next.js

Next.js 15 conversion of the Medicare Information Pro website.

## Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS 3
- Framer Motion
- Lucide React

## Development

```bash
pnpm install
pnpm dev
```

Pages are converted one at a time with client approval between each.
